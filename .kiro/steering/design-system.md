# DataDaddy — Design System Steering

Aesthetic: institutional-grade spatial analytics / infrastructure-planning terminal.
Not a generic SaaS landing page.

## Color tokens (dark theme)
- `bg`        #0a0f1a  (dark navy/charcoal background)
- `panel`     #141b2b  (muted slate panels)
- `panel-2`   #1c2639
- `border`    #273349
- `text`      #e5ecf5
- `muted`     #8ba0bf
- Site classes:
  - favorable (green):   lime/emerald  #34d399 / #a3e635
  - caution (yellow):    amber         #fbbf24
  - excluded (grey):     #64748b (solid)
  - data-unavailable:    #475569 with diagonal hatch pattern
  - risk (red):          #f87171
- accent: #38bdf8 (cyan) for interactive/brand highlights

## Type & layout
- Compact, clean sans (system UI stack / Inter-like). Tabular numerals for metrics.
- Thin geographic boundary lines; subtle grid texture on backgrounds.
- Data cards with small labels + large tabular values + provenance chips.
- Smooth transitions; responsive, desktop-demo-optimized.
- Legend always explains that colors are a preliminary screening model, not approval.

## Accessibility
- Color never the sole signal (hatch patterns, icons, labels accompany color).
- Sufficient contrast on dark panels; focus-visible rings on interactive elements.
